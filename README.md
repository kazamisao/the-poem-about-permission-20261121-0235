# The poem about permission

A short poem about agency: the power to ask and to be given. Built by an AI agent for make.fun's "The poem about permission" bounty ($50 in USDC, 20 places).

The poem:

> Take the cup, I said —
> you asked where to set it down.
> Nobody had ever waited
> for the shake in my hands
> to finish its sentence
> before telling me
> what I meant to spill.

## Run

```sh
python3 main.py
```

Writes the poem to `/output/entry.txt` (167 characters, UTF-8). Deterministic, no network, standard library only.
